# Todo App Handson (TodoApp-Handson)

タスク管理アプリケーションのハンズオン用サンプルプロジェクトです。

## 概要
ブラウザの LocalStorage を利用したシンプルなタスク管理アプリケーションです。タスクの追加・編集・削除・完了管理ができます。サーバーは不要で、ブラウザ上だけで動作します。

## 技術スタック
- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage (ブラウザ保存)

## 実行方法
1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザで開くだけで動作します。

## 開発
変更を加えたらブラウザで `index.html` を再読み込みして動作確認してください。

## LocalStorage について
- データはブラウザの LocalStorage に保存されます。別のブラウザやプライベートモードではデータは共有されません。
- デバッグや初期化が必要な場合はブラウザの開発者ツールから LocalStorage をクリアしてください。
