# Todo App Handson

Todoアプリのハンズオン用サンプルプロジェクトです。

## 概要
ブラウザのLocalStorageを利用したシンプルなタスク管理アプリケーションです。タスクの追加、編集、削除、完了管理ができます。

## 技術スタック
- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage (ブラウザ保存)

## 実行方法
1. このリポジトリをクローンまたはダウンロードします。
2. ローカルのファイルをブラウザで開くだけで動作します。
   - 例: index.html をブラウザで開く

## 開発
簡単な開発フロー:
- 変更を加えたらブラウザで index.html を再読み込みして動作を確認してください。

## LocalStorageについて
- データはブラウザのLocalStorageに保存されます。別のブラウザやプライベートモードではデータは共有されません。
- デバッグや初期化のためにLocalStorageをクリアする必要がある場合は、ブラウザの開発者ツールから操作してください。
